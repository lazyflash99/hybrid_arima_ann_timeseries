Does adding a neural network to ARIMA forecast better?

Zhang (2003) forecasts a series as an ARIMA forecast plus a neural-network forecast of ARIMA's errors. We reproduced the method, built an Extension that lets one network combine everything, and tested both on 11 datasets with stricter validation. Every number and curve on this page is loaded from the files our Python code wrote.

1. The idea, step by step
